# Pathfinder 2E Encounters - Overview

Encounter mode (also called _initiative_) changes how time flows in a scene. Use it when you need to track time closely, such as during combat or exploration.

The commands in this help file, and in the other encounter help files, run encounter mode in a scene. To take part in an encounter, you must join the scene, not just watch it.

For all commands, `e`, `initiative`, and `init` are short for `encounter`: `e/view` is the same as `encounter/view`. The help files spell out `encounter`, but you can use any of these.

`encounter/view` shows each combatant's ID: `#1`, `#2`, and so on. An encounter never reuses an ID, so `#3` is the same combatant for the whole fight. Any command that targets someone takes either the combatant's ID or their name, as long as no other combatant has the same name.

## Help file directory

Due to the length of these help files, we strongly suggest reading them on the web portal.

- `help encounter_player`: Player encounter commands (joining, your encounter sheet, the initiative table, Hero Points). [Read it on the web](/help/pf2e_encounter_player).
- `help encounter actions`: Player commands for acting in an encounter (actions, Strikes, and spells). [Read it on the web](/help/pf2e_encounter_actions).
- `help encounter_cover`: Cover and concealment, and finding hidden creatures. [Read it on the web](/help/pf2e_encounter_cover).
- `help encounter_conditions`: Being grabbed or held, conditions that limit your actions, and afflictions. [Read it on the web](/help/pf2e_encounter_conditions).
- `help encounter_gear`: Using the items you carry in an encounter. [Read it on the web](/help/pf2e_encounter_gear).
- `help encounter_runner`: GM commands for running an encounter (starting it, adding creatures, initiative order, difficulty, ending it). [Read it on the web](/help/pf2e_encounter_runner).
- `help encounter_creatures`: GM commands for running a creature (how its Strikes, abilities, auras, and spells work). [Read it on the web](/help/pf2e_encounter_creatures).
- `help encounter_creatureimport`: GM commands for adding a custom creature to an encounter. [Read it on the web](/help/pf2e_encounter_creatureimport).
- `help encounter_gm`: GM commands for acting for creatures, and undoing changes. [Read it on the web](/help/pf2e_encounter_gm).

## Bonuses and penalties

The game tracks a bonus or penalty that lasts for a while, such as from Bless, Heroism, or a potion, as an effect. `effect/add <who>=<effect>` applies an effect to a combatant, such as `effect/add #3=bless`. The game adds the effect's bonuses and penalties to every roll they affect, and ends the effect on its own when its duration runs out. See `help effects` or [read it on the web](/help/pf2e_effects) for more information.
